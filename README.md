## المميزات الرئيسية (Key Features)

1. 🌐 **دعم كامل للغتين (Arabic & English Corpus Processing):**
   * تبديل سلس بين معالجة النصوص العربية والإنجليزية بإعدادات مخصصة وخوارزميات متخصصة لكل لغة.
2. 🔒 **خصوصية مطلقة (100% Client-Side Privacy):**
   * جميع عمليات القراءة والتنظيف والتحليل والضغط تتم داخل ذاكرة متصفحك مباشرة.
3. 👁️ **إبراز الفروق التفاعلي (Interactive Visual Diff Highlighter):**
   * خوارزمية ذكية لمقارنة النصوص (Token-based LCS Diff) تبرز الأجزاء المحذوفة باللون الأحمر مع خط شطب، والإضافات باللون الأخضر، مع إمكانية التبديل بين وضع الفروق الملونة والنص العادي.
4. 🔍 **معاينة مصغرة سريعة (Inline Small Previews):**
   * عرض معاينات مقتضبة مباشرة داخل جدول الملفات مع إمكانية توسيعها وطيها لمراجعة النتائج فوراً دون فتح النوافذ المنبثقة.
5. ⚡ **سرعة وأداء فائق (Blazing Fast):**
   * معالجة مئات الملفات النصية وملايين الحروف في أجزاء من الثانية.
6. 📦 **ضغط وتنزيل فوري (In-Browser ZIP Archiving):**
   * تنزيل جميع الملفات المعالجة داخل ملف مضغوط `.zip` بضغطة زر واحدة باستخدام مكتبة JSZip المدمجة محلياً.
7. 📑 **تصدير سجل القرارات (Decisions Log Export):**
   * تصدير ملف `CSV` موثق بترميز UTF-8 يحوي القرارات المنهجية المتخذة والتعليل اللغوي لتوثيق إجراءات البحث العلمي.
8. 🎨 **مظهر مريح يدعم الوضعين الداكن والفاتح (Fixed Dark / Light Modes):**
   * واجهة متجاوبة وأنيقة بخطوط عربية ولاتينية مقروءة، مع دعم التبديل السلس بين الثيم الفاتح والثيم الداكن وحفظ التفضيل محلياً.

## خيارات المعالجة حسب اللغة (Cleaning Options)

### 🇸🇦 خيارات المعالجة العربية (Arabic Pipeline)
- **إزالة التشكيل (Diacritics):** حذف الحركات والتنوين والشدة والسكون وضبط المصاحف.
- **تطبيع الألف (Normalize Alef):** توحيد أشكال الألف (`أ`, `إ`, `آ`, `ٱ`) إلى ألف مجردة (`ا`).
- **تطبيع الياء (Normalize Yaa):** توحيد الألف المقصورة والياء الفارسية (`ى`, `ی`) إلى ياء (`ي`).
- **إزالة الكشيدة / التطويل (Tatweel):** إزالة المدود الزخرفية بين الحروف.
- **إزالة وسوم HTML / Markdown:** تنقية النصوص من أكواد الويب والتنسيقات.
- **إزالة الروابط وعناوين البريد:** تنظيف روابط الويب والـ URLs.
- **المحارف الغريبة والإيموجي:** تنظيف محارف التحكم والـ Unicode الخفية والرموز التعبيرية.
- **تنظيف الأرقام:** حذف الأرقام المشرقية والمغربية اختيارياً.
- **تنظيف علامات الترقيم:** إزالة الفواصل والنقاط وعلامات الاستفهام والتعجب اختيارياً.
- **تطبيع المسافات والأسطر:** اختزال المسافات المتكررة وتقليص الأسطر الفارغة.

### 🇬🇧 خيارات المعالجة الإنجليزية (English Pipeline)
- **فك الاختصارات (Expand Contractions):** تحويل الاختصارات مثل `don't` إلى `do not` و `they'll` إلى `they will`.
- **تحويل لحروف صغيرة (Lowercase):** توحيد كافة النصوص إلى Case صغيرة.
- **إزالة علامات النبر واللكنات (Remove Accents / Diacritics):** تطبيع المحارف المشكولة (مثل `résumé` إلى `resume`).
- **تنقية الأكواد (HTML & Markdown Stripping):** إزالة الوسوم البرمجية والتنسيقات.
- **إزالة الروابط والبريد (Remove URLs & Emails):** كشف وحذف عناوين الويب والإيميل.
- **حذف الرموز التعبيرية والمحارف غير المقروءة (Emojis & Non-ASCII):** إزالة الإيموجيات ومحارف التحكم.
- **إزالة الأرقام (Remove Digits):** حذف كافة الأرقام اختيارياً.
- **إزالة علامات الترقيم (Remove Punctuation):** تنظيف علامات الترقيم والرموز الخاصة اختيارياً.
- **تطبيع المسافات والأسطر الفارغة (Normalize Whitespace & Blank Lines):** تنظيم الفراغات وهيكل الفقرات.
